GETFLEXSPACE — LOGO FILES

The selected uppercase logo, supplied in three colorways:

Color: charcoal lettering #0F1E29 and orange x #F7661B.
White: all lettering, including the x, is pure white #FFFFFF.
Black: all lettering, including the x, is pure black #000000.

Each colorway includes:
- SVG: scalable vector outlines, with no fonts or embedded raster images.
- PNG: 4800 x 880 pixels with a transparent background.

All six files have matching proportions, spacing and transparent margins.
The outlines were vectorized from the flat logo in the selected design preview.

Use SVG for building signage, print layouts and scalable website display.
Use PNG where an image upload is required. Place the white logo on a dark
background; its background remains transparent.

Preserve the proportions when resizing. Color values are specified in sRGB.
